# EventTrack Campus Pin

Approved direction: a green location pin with a campus doorway cut into its center.
Created using the built-in image generation tool. The original PNG is preserved
as `campus_pin.png`; `campus_pin_mark.png` trims transparent canvas margins for UI use.

`python scripts/export_brand_assets.py` exports platform icon and launch-image sizes
without changing the approved symbol. In-app marks use the existing #28A776 green,
or white when displayed on green headers.

## Generation prompt

Use case: logo-brand. Generate a polished standalone logo symbol for EventTrack,
a university student event attendance app using venue geofencing. Chosen concept:
Campus Pin. Create one compact rounded location-pin silhouette with a simple OPEN
CAMPUS DOORWAY cut into its center as transparent negative space. The doorway
should be a clean architectural opening with two sturdy vertical sides and a
gently rounded lintel; its open bottom should connect elegantly into the inner
space of the pin, making a distinctive unified symbol for entering a campus venue.
Strong recognizable outer pin silhouette with a rounded upper body and softly
tapered lower point, balanced modern proportions. Friendly academic brand,
professional and understated. Flat solid bright app green #28A776 only; all
negative space and the background genuinely transparent. Crisp vector-like edges
with generous stroke weight so it works at 24 pixels. Center one single symbol
on a square canvas, occupying roughly 70 percent of its width with ample clear
margins for mobile launcher use. No letters, no ET monogram, no wordmark, no
calendar, no checkmark, no tiny building details, no graduation cap, no enclosing
background tile, no decorative shapes, no yellow, no orange, no dark green, no
gradients, no shadows, no texture, no 3D, no mockup, no concept board. Deliver the
actual usable logo artwork, not a screenshot of a design presentation.
